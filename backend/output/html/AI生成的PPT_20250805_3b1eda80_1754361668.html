Redis Stream 数据结构解析

命令端操作 - 生产者端

• xadd 命令：功能是向 Stream 中添加新消息，使用场景如实时日志记录，语法格式为 xadd key ID field value。

• xrange 命令：用于按顺序获取 Stream 中的消息，可指定范围，场景如查看一段时间内日志，语法指定起始和结束 ID。

• xlen 命令：获取 Stream 中消息数量，方便了解数据规模，语法简单直接。

• del 和 xdel 命令：del 删除整个 Stream，xdel 删除指定消息，用于清理数据。

命令端操作 - 消费端 - 单消费者

• xread 指令：读取指定消息 ID 后消息，语法指定 Stream 名称和起始 ID。

• 阻塞读取：以阻塞方式从尾部读取消息，设置超时时间，适用于实时处理，操作要点需注意阻塞时间设置。

• 消息 ID 记录：强调顺序消费时记录消息 ID 重要性，避免重复或遗漏处理。

命令端操作 - 消费端 - 消费群

• 关键元素作用：说明消费组中 last_delivered_id 记录已交付消息，pending_ids[] 记录待处理消息。
