## 如何测试

### 1. 打开小程序
- 使用微信开发者工具打开 `frontend` 目录
- 确保在开发者工具中正确配置AppID

### 2. 测试登录功能
1. 页面首次加载会显示**首页**
2. 显示"用户未登录"状态
3. 点击"点击登录"按钮
4. 进入登录页面，点击"微信快速登录"
5. 授权用户信息后自动登录成功
6. 返回首页显示"用户已登录"状态

### 3. 测试页面导航
- **首页**: 显示登录状态和功能菜单
- **我的课件**: 显示模拟课件列表
- **个人中心**: 显示用户信息和设置选项

### 4. 测试功能按钮
- 大部分按钮会显示"功能开发中"提示
- 已实现基础的页面跳转逻辑
- 登录/退出功能正常工作

## 登录测试说明
- 当前使用模拟登录，无需真实微信账号
- 登录后会在本地存储保存用户信息
- 支持退出登录功能
- 页面会自动检查登录状态
