# 服务器性能测试使用说明

## 📋 测试目标

模拟20个并发客户端访问服务器，测试除了Coze生成PPT和练习生成之外的所有API端点，验证能否在1分钟内完成处理（达到约20 QPS）。

## 🚀 快速开始

### 方法1: 使用简化版测试脚本（推荐）

```bash
# 运行简化版测试
node simple_performance_test.js
```

### 方法2: 使用完整版测试脚本

```bash
# 运行完整版测试（包含更多端点和详细统计）
node performance_test.js
```

## 🔧 故障排除

### 常见问题

1. **SSL证书错误**
   ```
   Error: self signed certificate
   ```
   **解决**: 脚本已设置 `rejectUnauthorized: false` 忽略SSL验证

2. **连接超时**
   ```
   Error: connect ETIMEDOUT
   ```
   **解决**: 检查服务器是否正常运行，防火墙设置

3. **认证失败 (完整版测试)**
   ```
   401 Unauthorized
   ```
   **解决**: 脚本会自动使用Mock token继续测试

4. **端口不可达**
   ```
   Error: connect ECONNREFUSED
   ```
   **解决**: 确认服务器在9000端口正常运行

## 🎯 性能优化建议

根据测试结果，如果性能未达标，可以考虑：

### 服务器端优化:
1. **数据库优化**: 添加索引，优化查询
2. **缓存优化**: 使用Redis缓存热点数据
3. **连接池**: 优化数据库连接池配置
4. **静态文件**: 使用CDN或Nginx处理静态资源

### 应用级优化:
1. **路由优化**: 减少中间件链长度
2. **响应压缩**: 启用gzip压缩
3. **并发处理**: 优化Go routine使用
4. **内存管理**: 减少不必要的内存分配

### 基础设施优化:
1. **服务器配置**: 增加CPU、内存
2. **网络带宽**: 提升网络带宽
3. **负载均衡**: 部署多实例负载均衡
